

These are the 7 verbs that can act as main/TAM marking verbs in main clauses.
The 4 forms are (in order): atemporal (atem), continual (cont), remote, departing (depart).

- MYU Completative / PAT Exhaustive
ʔi.tĩ              => iɾĩ
tyi.tĩ             => dyiɾĩ
ʔi.tə.sa.r         => iɾesar
ʔi.tã.nã           => iɾã

- RUS Suportive
hɪ.we.k            => hiwehh
hi.we.k            => hiwehh
hɪ.we.se.r         => hiweser
hɪ.we.kã           => hiwehã

- MYU Looming
ã.k                => ãhh
ã.nũ.k             => ãhh
ã.si.r             => ãsir
wã.kã              => wãhã

- RUS Exceptional
kai.tu             => gaiɾu
kə.kai.tu          => gehaiɾu
ki.tswi.sa.r       => gitwisar
ki.twĩ             => giɾwĩ

- RUS Explosive / MYU Expansive / PAT Reaching
lã.na.ti.tsũ       => lãɾisuv
lã.tə.lã.ni.ti.tsã => lãɾelãɾitã
lã.ti.tsi.r        => lãɾitʃir
lã.ti.tsã.nã       => lãɾitã

These two verbs aren't part of the double TAM system, but can be used without it, and instead of having a single complementive adposition they take the full set of motion adpostions regularly.
